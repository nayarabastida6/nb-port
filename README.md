## Instalación y ejecución local

Para ejecutar el proyecto en tu entorno local, necesitas tener instalado [Node.js](https://nodejs.org/) y npm.

### 1. Clonar el repositorio

```bash
git clone URL_DE_TU_REPOSITORIO
```

Sustituye `URL_DE_TU_REPOSITORIO` por la dirección real del repositorio en GitHub.

### 2. Acceder a la carpeta del proyecto

```bash
cd portfolio-nayara
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Iniciar el servidor de desarrollo

```bash
npm run dev
```

Astro mostrará en la terminal la dirección local donde podrás visualizar el proyecto. Por defecto, suele ser:

```text
http://localhost:4321/
```

### 5. Comprobar la compilación

```bash
npm run build
```

Este comando permite comprobar si el proyecto se compila correctamente para su despliegue.

## Estructura del proyecto

```text
portfolio-nayara/
├── public/
├── src/
│   ├── pages/
│   │   └── index.astro
│   └── styles/
│       └── global.css
├── astro.config.mjs
├── package.json
├── package-lock.json
├── tsconfig.json
└── README.md
```

### Organización de los archivos

* `public/`: contiene archivos estáticos, como imágenes, iconos y otros recursos.
* `src/pages/index.astro`: contiene la página principal del portfolio.
* `src/styles/global.css`: reúne los estilos globales y las reglas visuales de la web.
* `astro.config.mjs`: contiene la configuración de Astro.
* `package.json`: define los metadatos del proyecto, sus dependencias y los comandos disponibles.
* `package-lock.json`: registra las versiones concretas de las dependencias instaladas.
